📊 HR Analytics Dashboard — Power BI

An end-to-end **HR Analytics project** built using **Python, Pandas, Power BI, Power Query, and DAX** to analyze employee attrition, workforce demographics, job satisfaction, salary trends, and key HR performance indicators.

The project demonstrates the complete data analytics workflow — from **data cleaning and exploratory analysis to data visualization, dashboard development, and business insights**.

---

## 🚀 Project Overview

Human Resource teams need data-driven insights to understand employee behavior, identify attrition patterns, and improve workforce planning.

This project analyzes HR data to answer important business questions such as:

* What is the overall employee attrition rate?
* Which departments have the highest attrition?
* Which age groups are more likely to leave?
* How does job satisfaction affect attrition?
* What is the relationship between salary and employee retention?
* Which job roles experience the highest employee turnover?
* How does overtime influence attrition?
* What are the major workforce demographics?

---

## 🎯 Project Objectives

The main objectives of this project are:

1. Clean and preprocess raw HR data.
2. Perform exploratory data analysis using Python.
3. Identify important HR trends and patterns.
4. Create meaningful KPIs using DAX.
5. Build an interactive Power BI dashboard.
6. Analyze employee attrition and workforce demographics.
7. Generate actionable business insights.
